# 中轴智游 · 北京中轴线文化导览智能体

数字素养实践活动参赛作品（离线演示版）。双击 `index.html` 即可打开，不需要服务器、不需要联网、不需要 API key。

## 这是什么

一个围绕**北京中轴线**的文化导览智能体演示页：路线、点位讲解、知识检索、问答，全部在浏览器里跑。

- `index.html` — 主演示页（约 31 KB）
- `offline.html` — 离线知识版（约 606 KB，内含完整知识库）

两者都是**单文件**：没有构建步骤、没有依赖、没有后端。`git clone` 之后双击就能看，这是它作为参赛作品和演示材料的设计前提——评审机上不会有人先跑一遍 `npm install`。

## 怎么用

```bash
git clone https://github.com/kevindurant735rocket-creator/zhongzhouyou-demo
open index.html        # macOS
open offline.html      # 含完整知识库的那一版
```

或者直接看在线版本：本仓库的 Pages。

## 15 个点位

演示页覆盖 15 个中轴线点位，每个带讲解文字与知识条目。点位选取按南北轴线顺序，走一遍约 2 小时。

## 边界

这是**演示作品**，不是完整产品：

- 知识库是静态快照，不是实时抓取或检索
- 没有真实的模型推理，所谓"智能体"是预置逻辑 + 知识匹配
- 未做移动端适配，桌面浏览器下体验最佳
- 不收集任何数据，没有账号也没有网络请求
